  # Atlas QA                                                                                                                                                                                                       
  **Navigate Quality with Confidence**                                                                                                                                                                             
  A professional website for Atlas QA - your QA roadmap partner.

  ## Quick Setup (5 minutes)

  ### 1. Customize the content

  Open `index.html` and replace:

  | Find | Replace with |
  |------|--------------|
  | `YourName` | Atlas QA |
  | `your.email@example.com` | Your email address |
  | `github.com/yourusername` | https://github.com/atlasqa |
  | `linkedin.com/in/yourprofile` | Your LinkedIn profile |
  | `twitter.com/yourhandle` | Your Twitter/X profile (or remove) |
  | `[X] years` | Your experience level |
  | `[Location]` | Your city/timezone |
  | `[personal touch...]` | A hobby or interest |
  | Project cards | Your actual projects (or remove if starting fresh) |

  ### 2. Deploy for FREE

  **GitHub Pages**

  1. Go to https://github.com/nirmalcse/atlasqa
  2. Settings > Pages > Enable
  3. Branch: main / Folder: root
  4. Your site: https://nirmalcse.github.io/atlasqa
